# Private security reporting

Never post live links, subscription URLs, credentials, private keys, complete core
configs or private databases in public issues.

Use GitHub private security reporting **if enabled** at
https://github.com/mohammadhejazirad/tunnelctl. If unavailable, request a private
maintainer contact without publicly disclosing the vulnerability. No enabled
advisory channel or email address is assumed.

Provide versions, OS/kernel, redacted reproduction and impact. Pre-1.0 project:
no guaranteed SLA or independent security audit. Supported candidate scope is
Linux amd64 Shadowsocks TCP proxy with approved core. TUN/unsupported targets must
not be used as a security boundary. See docs/security.md.
